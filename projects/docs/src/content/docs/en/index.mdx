discord-mcbe is an open-source bridge between a Minecraft Bedrock Edition world and a text channel in your Discord server. It relays chat, join and leave events, player lists, commands, and live status through one bot.

## <Icon name="download" />Downloads

### <Icon name="rocket" />Launcher

Use the launcher to install and update the discord-mcbe server. When this device matches a supported build, its download button is selected automatically.

<LauncherDownloads locale="en" />

### <Icon name="puzzle" />Minecraft add-ons

Use the `local` asset for a regular hosted world and the `bds` asset for Bedrock Dedicated Server. Match its version to the server installed by the launcher.

<AddonDownloads locale="en" />

Continue with the [installation guide](/en/installation/setup-bot/) for Discord bot creation, extraction, and configuration.

## <Icon name="star" />What it can do

<CardGrid stagger>
  <Card title="Two-way chat" icon="messages">
    Relay Minecraft chat to Discord and messages from one Discord channel to every connected world. Replies
    and attachment counts are represented in game too.
  </Card>
  <Card title="Multiple worlds" icon="puzzle">
    Connect regular hosted worlds and Bedrock Dedicated Server (BDS) worlds at the same time, then target them
    by name.
  </Card>
  <Card title="Operations commands" icon="terminal">
    Check latency and player lists or execute Minecraft commands from Discord. Administrative commands are
    restricted to Discord administrators by default.
  </Card>
  <Card title="Extensible" icon="setting">
    Configure message filters and text overrides, then use JavaScript custom scripts to consume events and the
    Minecraft API wrappers.
  </Card>
</CardGrid>
