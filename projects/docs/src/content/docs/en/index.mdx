<Aside type="note" title="Documentation for stable v4">
  These docs cover discord-mcbe **v4** and later. When upgrading from v3 or earlier, back up the existing
  installation and follow the [installation guide](/en/installation/setup-bot/) to set it up in a separate
  directory.
</Aside>

## <Icon name="list-format" />Installation path

1. [Set up the discord-mcbe server](/en/installation/setup-bot/)
2. [Install the add-on in a regular world or BDS](/en/installation/setup-world/)
3. Start the world and connect it

If you run into trouble during setup, the [troubleshooting guide](/en/guides/troubleshooting/) collects checks by symptom and log message.
