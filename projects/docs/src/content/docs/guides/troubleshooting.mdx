最初に、サーバーとアドオンが同じリリースであること、`.env`や`config.json`を変更した場合は再起動済みであることを確認してください。

## Botが起動しない

### `Invalid environment variables`と表示される場合

- `.env`が`start.bat`または`start.sh`と同じフォルダーにあるか確認します。
- `DISCORD_TOKEN`、`GUILD_ID`、`CHANNEL_ID`が空でないか確認します。
- IDにはチャンネル名やURLではなく、18〜20桁程度の数値IDを指定します。
- ポートには正の整数を指定します。

### `error: An invalid token was provided`と表示される場合

- `DISCORD_TOKEN`に設定したBotのトークンを間違えていないか、正しく設定されているかを確認します。
- トークンを設定しているのにこのエラーが出る場合は、[Discord Developer Portal](https://discord.com/developers/applications)から新しいトークンを設定してください。

### `error: Used disallowed intents`と表示される場合

[Discord Developer Portal](https://discord.com/developers/applications)の `Bot > Privileged Gateway Intents > Message Content Intent` を有効にして再起動してください。

### `Error: Failed to find the guild`と表示される場合

- `GUILD_ID`に設定したサーバーIDが正しいか確認します。
- Botがそのサーバーに参加しているか確認します。

### `Error: Failed to find the channel`と表示される場合

- `CHANNEL_ID`に設定したチャンネルIDが正しいか確認します。
- Botにそのチャンネルを見る権限があるか確認します。

### `Error: The channel (ID: 0000000000) is not a text channel`と表示される場合

`CHANNEL_ID`に設定したチャンネルがテキストチャンネルであることを確認します。ボイスチャンネルやスレッドでは動作しません。

### `Invalid config.json`と表示される場合

エラーに表示されたキーを確認します。JSONの末尾カンマ、文字列の引用符、正の整数が必要な項目の`0`に注意してください。直せない場合は現在のファイルをバックアップし、再起動して初期設定を生成してから必要な値だけ戻します。

## スラッシュコマンドが表示されない

- discord-mcbeを再起動し、`Logged in as ...`の後にエラーがないか確認します。
- Discordクライアントを再読み込みします。(反映に時間がかかる場合があります。)

`/command`と`/panel`は管理者にだけ表示されます。`/ping`と`/list`があれば正常です。

## チャット連携が動作しない

- メッセージを送ったチャンネルが`CHANNEL_ID`と同じか確認します。
- Botに「チャンネルを見る」「メッセージを送信」「埋め込みリンク」「ファイルを添付」「メッセージ履歴を読む」が許可されているか確認します。
- `bot.discord_message_filter`の`cancel`条件に一致していないか確認します。
- ワールドが接続済みか`/ping`で確認します。

Botが送信したメッセージはループ防止のためMinecraftへ転送されません。

## Minecraftと接続できない

### <Icon name="laptop" />ローカルワールドの場合

- `bds`ではなく`local`用パックを使ってください。
- `discord-mcbe-local-*.mcpack`をビヘイビアーパックとして有効にしたか確認します。
- ワールドとdiscord-mcbeサーバーを起動してから、ホストが`/connect localhost:3063`を実行します。
- 別端末からは`localhost`ではなく、discord-mcbeが動作している端末のIPアドレスを指定します。

#### `Required addon not installed`と表示される場合

WebSocket自体には接続できていますが、アドオンが正しく動作していません。パックが有効か、ベータAPI が有効かを確認します。

### <Icon name="server" />Bedrock Dedicated Serverの場合

- `local`ではなく`bds`用パックを使ってください。
- `world_behavior_packs.json`等にアドオンが追加されていて、有効化されているか確認します。
- ベータ API も有効化してください。
- `config/default/permissions.json`の`allowed_modules`リストに`@minecraft/server-net`モジュールが追加されているか確認します。
- discord-mcbeのbot側が起動していることを確認してからBDSを起動してください。
- 公式BDSアドオンはBDS本体のフォルダにある<code>{`config/${BDS_SCRIPT_MODULE_UUID}/variables.json`}</code>から接続先を読み取ります。ファイルを作成・編集し、BDSを再起動してください。
- `BRIDGE_URL`はBDSから見たdiscord-mcbeのWebSocket URLにします。URL内のポートは`.env`の`BRIDGE_PORT`と同じ値にしてください。
