import { Code, Tabs, TabItem } from '@astrojs/starlight/components';

discord-mcbeには、<a href="https://github.com/OmniacDev/MCBE-IPC" target="_blank" rel="noopener noreferrer">MCBE-IPC</a>を使った他のアドオンとの連携機能があります。
これにより、他のアドオンからdiscord-mcbeを経由してDiscordへメッセージを送信できます。

他のアドオンへのMCBE-IPCの導入方法は配布元の説明に従ってください。

:::caution
この機能は、同じワールドで有効になっている他のアドオンを信頼できることを前提としています。
悪意のあるアドオンが導入されている場合、Discordへ意図しない、または不適切なメッセージが送信される可能性があります。
なお、この機能は`config.json`の`bot.allow_addon_messages`を`false`にすることで無効化できます。
:::

この機能を無効にするには、`config.json`の`bot.allow_addon_messages`を`false`にします。無効にしても、導入・接続確認用の`ping`には応答します。

## discord-mcbeが導入されているか確認する

`dmc:ping`の応答は、`true`なら接続中、`false`なら導入済みですが未接続です。20tick以内に応答がなければ、discord-mcbeは導入されていません。この確認は起動時に一度だけ行ってください。

<Tabs syncKey="code">
<TabItem value="ts" label="TypeScript">

```ts
import { system } from '@minecraft/server';
import { IPC, PROTO } from 'mcbe-ipc';

export function getDiscordMcbeStatus(): Promise<boolean | undefined> {
  return Promise.race([
    IPC.invoke('dmc:ping', PROTO.Void, undefined, PROTO.Boolean),
    system.waitTicks(20).then(() => undefined),
  ]);
}
```

</TabItem>
<TabItem value="js" label="JavaScript">

```js
import { system } from '@minecraft/server';
import { IPC, PROTO } from 'mcbe-ipc';

export function getDiscordMcbeStatus() {
  return Promise.race([
    IPC.invoke('dmc:ping', PROTO.Void, undefined, PROTO.Boolean),
    system.waitTicks(20).then(() => undefined),
  ]);
}
```

</TabItem>
</Tabs>

## Discordへメッセージを送る

`dmc:send_message`へ送信元と[Discord Create Message API](https://docs.discord.com/developers/resources/message#create-message)形式のmessageを含むobjectをJSON文字列として送ると、Discordへメッセージが送信されます。

<Tabs syncKey="code">
<TabItem value="ts" label="TypeScript">

```ts
import { IPC, PROTO } from 'mcbe-ipc';

function sendDiscordMessage(source: string, message: Record<string, unknown>) {
  IPC.send('dmc:send_message', PROTO.String, JSON.stringify({ source, message }));
}

sendDiscordMessage('example-addon', {
  content: 'このメッセージは別のアドオンから送信しています',
});
```

</TabItem>
<TabItem value="js" label="JavaScript">

```js
import { IPC, PROTO } from 'mcbe-ipc';

function sendDiscordMessage(source, message) {
  IPC.send('dmc:send_message', PROTO.String, JSON.stringify({ source, message }));
}

sendDiscordMessage('example-addon', {
  content: 'このメッセージは別のアドオンから送信しています',
});
```

</TabItem>
</Tabs>

`source`には送信元のアドオン名を指定します。`message`では`embeds`など、JSONで表現できるCreate Message APIのフィールドも利用できます。添付ファイル本体の転送には対応していません。

## 接続イベントを受け取る

接続開始時に`dmc:connect`、切断時に`dmc:disconnect`が発火します。どちらもデータはありません。

```ts
import { IPC, PROTO } from 'mcbe-ipc';

IPC.on('dmc:connect', PROTO.Void, () => {
  // discord-mcbeへの接続が開始された
});

IPC.on('dmc:disconnect', PROTO.Void, () => {
  // discord-mcbeから切断された
});
```
