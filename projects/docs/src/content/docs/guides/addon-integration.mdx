import { Code, Tabs, TabItem } from '@astrojs/starlight/components';

discord-mcbeには、<a href="https://github.com/OmniacDev/MCBE-IPC" target="_blank" rel="noopener noreferrer">MCBE-IPC</a>を使った他のアドオンとの連携機能があります。
これにより、他のアドオンからdiscord-mcbeを経由してDiscordへメッセージを送信したり、アドオンが処理したチャットをDiscordへ表示したりできます。

他のアドオンへのMCBE-IPCの導入方法は配布元の説明に従ってください。

:::caution
この機能は、同じワールドで有効になっている他のアドオンを信頼できることを前提としています。
悪意のあるアドオンが導入されている場合、Discordへ意図しない、または不適切なメッセージが送信される可能性があります。
なお、この機能は`config.json`の`bot.allow_addon_messages`を`false`にすることで無効化できます。
:::

この機能を無効にするには、`config.json`の`bot.allow_addon_messages`を`false`にします。無効にしても、導入・接続確認用の`ping`には応答します。

## discord-mcbeが導入されているか確認する

`dmc:ping`の応答は、`true`なら接続中、`false`なら導入済みですが未接続です。20tick以内に応答がなければ、discord-mcbeは導入されていません。この確認は起動時に一度だけ行ってください。

<Tabs syncKey="code">
<TabItem value="ts" label="TypeScript">

```ts
import { system } from '@minecraft/server';
import { IPC, PROTO } from 'mcbe-ipc';

export function getDiscordMcbeStatus(): Promise<boolean | undefined> {
  return Promise.race([
    IPC.invoke('dmc:ping', PROTO.Void, undefined, PROTO.Boolean),
    system.waitTicks(20).then(() => undefined),
  ]);
}
```

</TabItem>
<TabItem value="js" label="JavaScript">

```js

import { IPC, PROTO } from 'mcbe-ipc';

    IPC.invoke('dmc:ping', PROTO.Void, undefined, PROTO.Boolean),

}
```

## Discordへメッセージを送る

`dmc:send_message`へ送信元と[Discord Create Message API](https://docs.discord.com/developers/resources/message#create-message)形式のmessageを含むobjectをJSON文字列として送ると、Discordへメッセージが送信されます。

<Tabs syncKey="code">
<TabItem value="ts" label="TypeScript">

```ts
import { IPC, PROTO } from 'mcbe-ipc';

function sendDiscordMessage(source: string, message: Record<string, unknown>) {
  IPC.send('dmc:send_message', PROTO.String, JSON.stringify({ source, message }));
}

sendDiscordMessage('example-addon', {
  content: 'このメッセージは別のアドオンから送信しています',
});
```

</TabItem>
<TabItem value="js" label="JavaScript">

```js
import { IPC, PROTO } from 'mcbe-ipc';

function sendDiscordMessage(source, message) {
  IPC.send('dmc:send_message', PROTO.String, JSON.stringify({ source, message }));
}

sendDiscordMessage('example-addon', {
  content: 'このメッセージは別のアドオンから送信しています',
});
```

</TabItem>
</Tabs>

`source`には送信元のアドオン名を指定します。`message`では`embeds`など、JSONで表現できるCreate Message APIのフィールドも利用できます。添付ファイル本体の転送には対応していません。

## チャットを処理するアドオンと連携する

`world.beforeEvents.chatSend`でチャットをキャンセルし、独自の形式で送り直すアドオンを導入していると、discord-mcbeはチャットを受け取れません。そのようなアドオンは、次の手順でチャットをdiscord-mcbeへ通知できます。通知されたチャットは通常のチャットと同じように扱われ、コンソールとDiscordに表示されます。

### 1. 起動時に登録する

`dmc:register`を起動時に一度だけ呼び出します。20tick以内に応答がなければ、discord-mcbeは導入されていません。

<Tabs syncKey="code">
<TabItem value="ts" label="TypeScript">

```ts
import { system } from '@minecraft/server';
import { IPC, PROTO } from 'mcbe-ipc';

interface RegisterResponse {
  protocol: number;
  connected: boolean;
  features: string[];
}

export async function registerToDiscordMcbe(source: string): Promise<RegisterResponse | undefined> {
  const response = await Promise.race([
    IPC.invoke(
      'dmc:register',
      PROTO.String,
      JSON.stringify({ source, protocol: 1, features: ['minecraft_chat'] }),
      PROTO.String,
    ),
    system.waitTicks(20).then(() => undefined),
  ]);
  return response === undefined ? undefined : (JSON.parse(response) as RegisterResponse);
}
```

</TabItem>
<TabItem value="js" label="JavaScript">

```js
import { system } from '@minecraft/server';
import { IPC, PROTO } from 'mcbe-ipc';

export async function registerToDiscordMcbe(source) {

      PROTO.String,
    ),
    system.waitTicks(20).then(() => undefined),
  ]);
  return response === undefined ? undefined : JSON.parse(response);
}
```

</TabItem>

| フィールド | 説明                                                               |
| ---------- | ------------------------------------------------------------------ |
| `source`   | アドオン名。以降の通知でも同じ値を使います                         |
| `protocol` | このページで説明している形式のバージョン。現在は`1`                |
| `features` | 利用する機能。チャットを通知する場合は`minecraft_chat`を指定します |

応答の`features`には、要求した機能のうちdiscord-mcbeが受け付けたものが入ります。`connected`は応答時点の接続状態です。

`minecraft_chat`を登録すると、discord-mcbeは自身によるチャットの中継を止め、アドオンからの通知だけをDiscordへ送ります。

### 2. チャットを通知する

Discordへ表示したいチャットごとに`dmc:on_chat_send`を送信します。全体チャットだけを通知するなど、どのチャットを通知するかはアドオン側で決めてください。

```ts
import type { Player } from '@minecraft/server';
import { IPC, PROTO } from 'mcbe-ipc';

function notifyChat(source: string, player: Player, message: string) {
  IPC.send(
    'dmc:on_chat_send',
    PROTO.String,
    JSON.stringify({
      source,
      playerId: player.id,
      message,
      formatting: { namePrefix: '[Team A] ' },
    }),
  );
}
```

| フィールド   | 説明                                             |
| ------------ | ------------------------------------------------ |
| `source`     | 登録時と同じアドオン名                           |
| `playerId`   | 発言したプレイヤーの`Player.id`                  |
| `message`    | 装飾を含まない本文                               |
| `formatting` | 送信者名と本文の前後に付ける文字列。省略できます |

`formatting`には次の4つを指定できます。いずれも省略でき、文字列のみ指定できます。

| フィールド      | 表示位置     |
| --------------- | ------------ |
| `namePrefix`    | 送信者名の前 |
| `nameSuffix`    | 送信者名の後 |
| `messagePrefix` | 本文の前     |
| `messageSuffix` | 本文の後     |

- 登録していないアドオンからの通知と、オンラインでないプレイヤーの通知は無視されます。
- discord-mcbeが未接続のときの通知は無視されます。接続状態を確認してから送る必要はありません。
- `formatting`を省略した場合、`Player.chatNamePrefix`などの値は自動では使われません。使いたい場合は、アドオン側で読み取って指定してください。
- `beforeEvents.chatSend`の`message`には`Player.chatMessagePrefix`がすでに含まれています。その`message`をそのまま送る場合は、`messagePrefix`を指定しないでください。
- `bot.allow_addon_messages`が`false`のとき、通知されたチャットはDiscordへ送信されません。

## Discordのチャットを表示する

discord-mcbeは、Discordから届いたチャットをワールドの全員に表示します。チャットのミュートなど、表示する相手をアドオン側で決めたい場合は、`dmc:register`の`features`に`discord_chat`を加えて登録します。

`discord_chat`を登録すると、discord-mcbeはDiscordのチャットを自分では表示せず、`dmc:discord_chat`でアドオンへ渡します。表示はアドオンが行ってください。

```ts
import { world } from '@minecraft/server';
import { IPC, PROTO } from 'mcbe-ipc';

IPC.on('dmc:discord_chat', PROTO.String, (json) => {
  const { text } = JSON.parse(json) as { text: string };
  for (const player of world.getPlayers()) {
    // 表示しないプレイヤーをアドオン側で決める
    if (player.hasTag('mute_discord')) continue;
    player.sendMessage(text);
  }
});
```

| フィールド | 説明                                                                  |
| ---------- | --------------------------------------------------------------------- |
| `text`     | そのまま表示できる文字列。`translation_overrides`の内容が反映されます |
| `message`  | 元になったDiscordのメッセージ                                         |

`message`は、discord.jsの`Message`からゲーム内で使える項目だけを残した形です。送信者をアドオン側のアカウント連携と結びつけたり、独自の形式で表示したりするときに使います。

```ts
{
  id: string,
  channelId: string,
  content: string,
  author: { id: string, username: string, displayName: string, bot: boolean },
  member: { displayName: string, roles: { id: string, name: string }[] } | null,
  attachments: { name: string, contentType: string | null }[],
  mentions: { users: author[], roles: { id: string, name: string }[], everyone: boolean },
  referencedMessage: { id, content, author, member } | null,
}
```

| フィールド          | 説明                                                                                                                                                                               |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `content`           | フィルターを通した本文。メンションは名前に置き換わっています。添付ファイルだけなら空文字列です                                                                                     |
| `author.id`         | DiscordのユーザーID                                                                                                                                                                |
| `author.bot`        | 送信者では常に`false`です（Botの発言は中継されません）。返信先では`true`になることがあります                                                                                       |
| `member`            | サーバー内での表示名とロール。返信先がWebhookや退出済みのユーザーのときは`null`です                                                                                                |
| `member.roles`      | 上位のロールから順に並びます。`@everyone`は含みません                                                                                                                              |
| `attachments`       | 添付ファイルのファイル名と種類。`contentType`は`image/png`などで、不明なときは`null`です                                                                                           |
| `mentions`          | メンションされたユーザーとロール。`users`の要素は`author`と同じ形です。通知付きの返信では、返信先のユーザーも`users`に入ります。`everyone`は`@everyone`か`@here`が使われたかどうか |
| `referencedMessage` | 返信先のメッセージ。返信でなければ`null`です。`content`はフィルターを通し、長さを切り詰めた本文                                                                                    |

- 対象はDiscordから届いたチャットだけです。接続時の通知などは、これまでどおりdiscord-mcbeが表示します。
- Discordのメッセージ1件につき、通知は1回です。本文と添付ファイルの両方があるメッセージでは、`text`が2行になります。
- `dmc:discord_chat`は同じワールドの全アドオンに届きます。ユーザーIDやロールを渡したくないアドオンがある場合は、`bot.allow_addon_messages`を`false`にしてください。
- `discord_chat`を登録するアドオンは、1つのワールドに1つだけにしてください。複数のアドオンが登録すると、それぞれが表示して重複します。
- `bot.allow_addon_messages`が`false`のときは登録が無視され、discord-mcbeが全員に表示します。
- 応答の`features`に`discord_chat`が含まれない場合、導入されているdiscord-mcbeはこの機能に対応していません。その場合もdiscord-mcbeが全員に表示します。

## 接続イベントを受け取る

接続開始時に`dmc:connect`、切断時に`dmc:disconnect`が発火します。どちらもデータはありません。

```ts
import { IPC, PROTO } from 'mcbe-ipc';

IPC.on('dmc:connect', PROTO.Void, () => {
  // discord-mcbeへの接続が開始された
});

IPC.on('dmc:disconnect', PROTO.Void, () => {
  // discord-mcbeから切断された
});
```

## 型と定数を利用する

バンドラーを使っているアドオンは、npmパッケージ`@discord-mcbe/shared`からチャンネル名、機能名、ペイロードの型と検証関数を利用できます。

```ts
import { IPC, PROTO } from 'mcbe-ipc';
import { AddonChannel, type AddonChatSend } from '@discord-mcbe/shared';

const payload: AddonChatSend = {
  source: 'example-addon',
  playerId: player.id,
  message: 'hello',
};
IPC.send(AddonChannel.ChatSend, PROTO.String, JSON.stringify(payload));
```

| エクスポート                                     | 内容                                         |
| ------------------------------------------------ | -------------------------------------------- |
| `AddonChannel`                                   | チャンネル名（`dmc:register`など）           |
| `AddonFeature`                                   | 機能名（`minecraft_chat`など）               |
| `AddonRegisterRequest` / `AddonRegisterResponse` | `dmc:register`の要求と応答の型               |
| `AddonChatSend` / `AddonSendMessage`             | `dmc:on_chat_send` / `dmc:send_message`の型  |
| `AddonDiscordChat` / `AddonDiscordMessage`       | `dmc:discord_chat`と、その`message`の型      |
| `safeParseAddonRegisterResponse`                 | `dmc:register`の応答を検証する関数           |
| `safeParseAddonDiscordChat`                      | `dmc:discord_chat`のペイロードを検証する関数 |
