<Aside type="note" title="このページはv4正式版向けです">
  ランチャーv2でv4正式版をインストールします。v3から移行する場合は、既存環境をバックアップして別のフォルダーへセットアップし、以下の手順で設定を作成してください。v3用アドオンとv4サーバーには互換性がありません。
</Aside>

## <Icon name="list-format" />必要なもの

| 項目         | 要件                                                        |
| ------------ | ----------------------------------------------------------- |
| Discord      | Botを追加できるサーバーと「サーバーを管理」権限             |
| ホストOS     | Windows x64、Linux x64/arm64、またはmacOS x64/arm64         |
| Minecraft    | Bedrock Edition 1.21.100以降                                |
| ネットワーク | Discord API、GitHub Releases、npmレジストリへ接続できること |

ランチャーには必要なランタイムが含まれるため、通常のインストールではNode.jsやBunを別途用意する必要はありません。

## <Icon name="comment-alt" />Discord Botを作る

<Steps>

1. [Discord Developer Portal](https://discord.com/developers/applications)で **New Application** を選び、アプリケーションを作成します。

2. 左側の **Bot** を開き、**Reset Token** でBotトークンを発行して、安全な場所に保存します。

   <Aside type="danger" title="トークンはパスワードです">
     トークンをチャット、スクリーンショット、Gitリポジトリへ載せないでください。漏えいした場合はDeveloper
     Portalですぐに再発行します。
   </Aside>

3. **Bot → Privileged Gateway Intents** で **Message Content Intent** を有効にします。これが無効だとDiscordからMinecraftへメッセージ本文を転送できず、Botの接続も拒否される場合があります。

4. **Installation** のGuild Install設定（または **OAuth2 → URL Generator**）で`bot`と`applications.commands`のスコープを選び、次のBot権限を付けます。
   - チャンネルを見る（View Channels）
   - メッセージを送信（Send Messages）
   - 埋め込みリンク（Embed Links）
   - ファイルを添付（Attach Files）
   - メッセージ履歴を読む（Read Message History）

   頻繁にメッセージが流れるチャンネルでは「低速モードを回避」も任意で追加できます。チャンネル管理者権限は不要です。

5. 生成されたInstall Linkを開き、使用するDiscordサーバーへBotを追加します。

</Steps>

## <Icon name="approve-check-circle" />Discord IDをコピーする

Discordの **ユーザー設定 → 詳細設定 → 開発者モード** を有効にします。次に、対象のサーバーとチャット連携に使うテキストチャンネルを右クリックして、それぞれのIDをコピーします。

| 値           | コピー元                                              |
| ------------ | ----------------------------------------------------- |
| `GUILD_ID`   | Botを追加したDiscordサーバー                          |
| `CHANNEL_ID` | Minecraftとメッセージをやり取りするテキストチャンネル |

チャンネル固有の権限設定で、先ほどのBot権限が拒否されていないことも確認してください。

## <Icon name="rocket" />ランチャーを準備する

<LauncherDownloads locale="ja" />

<Steps>

1. ダウンロードしたzipを、書き込み可能な専用フォルダーへ展開します。Windowsでは、zipのプロパティに「ブロックの解除」が表示される場合、解除してから展開します。

2. `start.bat`または`start.sh`と同じ階層に`.env`ファイルを作り、保存・コピーした値を設定します。

   ```dotenv
   DISCORD_TOKEN=Botのトークン
   GUILD_ID=DiscordサーバーのID
   CHANNEL_ID=連携するテキストチャンネルのID
   # SOCKET_PORT=3063
   # BRIDGE_PORT=23191
   # BRIDGE_TRANSPORT=websocket
   ```

   値を引用符で囲む必要はありません。`SOCKET_PORT`と`BRIDGE_PORT`は、デフォルトポートが競合するときだけ変更します。BDS通信は既定でWebSocketです。

3. 最新の正式版をインストールします。

   **Windows（PowerShellまたはコマンドプロンプト）**

   ```powershell
   .\updater.exe latest
   .\start.bat
   ```

   **Linux / macOS**

   ```bash
   chmod +x updater start.sh
   ./updater latest
   ./start.sh
   ```

4. 初回起動時に`config.json`が作成されます。Botがオンラインになり、指定チャンネルに起動メッセージが届けば、サーバー側の準備は完了です。

</Steps>

続いて、[Minecraftワールドへアドオンを導入します](/installation/setup-world/)。

## <Icon name="cloud-download" />アップデートとバージョン切り替え

サーバーを停止してからランチャーを実行します。`config.json`、`.env`、`scripts/`は`app/`とは別に保存されるため更新後も引き継がれますが、更新前のバックアップを推奨します。

| 操作                         | Windows              | Linux / macOS      |
| ---------------------------- | -------------------- | ------------------ |
| 最新安定版へ更新             | `updater.exe latest` | `./updater latest` |
| 最新ベータへ更新（任意）     | `updater.exe beta`   | `./updater beta`   |
| バージョンを選択             | `updater.exe`        | `./updater`        |
| 指定バージョンをインストール | `updater.exe 4.0.0`  | `./updater 4.0.0`  |

v4ベータ版から正式版へ移行する場合は、`updater.exe latest --force`（Windows）または`./updater latest --force`（Linux / macOS）を実行し、アドオンも同じリリースへ更新します。ベータ版へ切り替える場合や、同じバージョンを再インストールする場合も、バージョン指定に`--force`を追加します。ランチャー自体の更新が必要と表示された場合は、ランチャーのリリースから新しいzipをダウンロードしてください。
