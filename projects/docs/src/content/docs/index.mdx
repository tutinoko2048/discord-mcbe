<Aside type="caution" title="v4はベータ版です">
  このドキュメントは`v4.0.0-beta`リリースを対象としています。安定版のv3とは、リリースアセット・設定ファイル・コマンドが異なります。
</Aside>

discord-mcbeは、Minecraft Bedrock EditionのワールドとDiscordサーバーのテキストチャンネルをつなぐオープンソースのブリッジです。普段のチャットに加え、参加・退出通知、プレイヤー一覧、コマンド実行、ステータスパネルをひとつのBotで扱えます。

## <Icon name="download" />ダウンロード

### <Icon name="rocket" />ランチャー

discord-mcbeサーバーのインストールとアップデートに使用します。この端末に対応するランチャーがある場合は、自動判定したダウンロードボタンが表示されます。

<LauncherDownloads locale="ja" />

### <Icon name="puzzle" />Minecraftアドオン

通常のワールドには`local`、Bedrock Dedicated Serverには`bds`アセットを使用します。ランチャーでインストールするサーバーと同じバージョンを選んでください。

<AddonDownloads locale="ja" />

Botの作成や展開後の設定を含む手順は、[導入ガイド](/installation/setup-bot/)を参照してください。

## <Icon name="star" />できること

<CardGrid stagger>
  <Card title="双方向チャット" icon="messages">
    MinecraftのチャットをDiscordへ、指定したDiscordチャンネルのメッセージを接続中の全ワールドへ届けます。返信と添付ファイル数もゲーム内で確認できます。
  </Card>
  <Card title="複数ワールド" icon="puzzle">
    通常のワールドとBedrock Dedicated
    Server（BDS）の両方に対応。複数のワールドを同時に接続し、名前を指定して操作できます。
  </Card>
  <Card title="運用コマンド" icon="terminal">
    Discordから応答速度、プレイヤー一覧、Minecraftコマンドの実行結果を確認できます。管理系コマンドはDiscordの管理者だけに制限されます。
  </Card>
  <Card title="拡張可能" icon="setting">
    メッセージフィルターや表示テキストを設定できるほか、JavaScriptのカスタムスクリプトからイベントとMinecraft
    APIラッパーを利用できます。
  </Card>
</CardGrid>
