  <Card title="双方向チャット" icon="comment-alt">

  </Card>
  <Card title="拡張可能" icon="puzzle">

## <Icon name="list-format" />導入の流れ

1. [discord-mcbeサーバーをセットアップする](/installation/setup-bot/)
2. [ローカルワールドまたはBDSにアドオンを導入する](/installation/setup-world/)
3. ワールドを起動して接続する

セットアップで詰まった場合は、[トラブルシューティング](/guides/troubleshooting/)にログ別の確認項目をまとめています。
